# Wealth & Asset Tracker
Personal finance tracker built with HTML, CSS, and JavaScript that runs entirely client-side.

## Features
- Log income and expense transactions
- View a live summary of income, expenses, and net balance
- Delete transactions
- Data persists on page refresh using localStorage

## How to Run
Simply open the file `index.html` in a browser.

## Tech used
- Semantic HTML (header, main, section, table, footer)
- CSS Flexbox for layout
- Vanilla JavaScript for DOM manipulation
- localStorage for state persistence
